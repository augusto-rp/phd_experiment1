This repository will contain files pertaining to the first experiment from my PhD.


This repository hosts data, analytical scripts, and code for an empirical study investigating whether exposure to humorous political cues directly increases objective attitudinal ambivalence.
The pregegistration can be viewed [here](https://osf.io/m5vh3/overview?view_only=9df22fee2aa94b5ea9bbceda845da342)


**Repository Content**

- /power_analysis : This folder contains the initial estimation of the requires sample size to archive an 80% statistical power. The effect sizes used to the estimation were based on meta analysis by [Walter et al.2018](https://academic.oup.com/hcr/article-abstract/44/4/343/4992917?redirectedFrom=fulltext&login=false) and [Burgers & Brugman, 2022](https://journals.sagepub.com/doi/10.1177/00936502211032100) However those might not be the best values to base the estimation on. Admittedly, there are a lot of assumptions in this estimation. That's why the initial sampling of 100 participants will also help get a better idea of the required sample size. 
- /pilot_analysis : This folder contains data, code and analysis of the pilot that was conducted to select the stimuli to be used in the experiment. There also an extensive README detailing the results and criteria for the selection.
- /100_analysis : This folder contains data, code and analysis of an initial sampling of 100 participants on the experiment. This will allow to get a better understanding on how is the experiment working and effect sizes. As of the date I'm writing this (**November 25/2026**) I'm actively conducting the analysis so expect usual changes in the R code.
